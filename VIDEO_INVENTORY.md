# Video Production Inventory

## Dashboard & Management
- **Video Dashboard Screen**: Central hub for managing video productions.
- **Equipment Management**: Tracks cameras, lighting, and gear assigned to productions (`video_equipment_screen.dart`).
- **Team Management**: Crew directory and role assignments (`video_team_screen.dart`).

## Tools & Features
- **Storyboard Presentation**: Specialized screen for presenting and reviewing storyboards (`storyboard_presentation_screen.dart`).
- **PDF Export Service**: Utility for generating and exporting production assets (`pdf_export_service.dart`).
- **Unified Projects**: Video projects are managed under a unified project structure alongside audio productions.

## Integrations
- Connects to desktop applications (Premiere Pro, DaVinci Resolve) via the Native Plugin Server to bridge mobile management and desktop editing.
