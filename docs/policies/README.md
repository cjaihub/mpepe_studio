# Oneova Official Legal, Trust & Company Protection Document Suite

**Version:** 1.0 · **Effective Date:** October 25, 2026  
**Entity:** Oneova Technologies Inc. (`https://oneova.app`)

This directory contains **Oneova's complete, ready-to-use legal, user-safety, commercial, and corporate data-protection document suite**—available in **3 ready-to-use formats**:
1. **Executive Printable PDFs (`docs/policies/pdf/*.pdf`)** — Typeset A4/Letter documents ready for board approval, staff/contractor signing, payment-partner KYC/KYB underwriting (Safaricom M-Pesa, MTN MoMo, Flutterwave, Stripe), investor data rooms, and regulator filings.
2. **Live Web Portal Pages (`public/*.html`)** — Responsive, fast-loading Light/Dark HTML pages ready for Firebase Hosting (`oneova.app/legal`, `/terms`, `/privacy`, `/guidelines`, `/child-safety`, `/biz-policy`, `/deletion`, `/law-enforcement`) for Google Play Console, Apple App Store, Meta, and TikTok verification.
3. **Offline In-App Legal Center (`lib/settings/screens/legal_policies_screen.dart`)** — Built directly into the Oneova Flutter app at `/legal` and **Me → Settings → Rules, Safety & Legal** (zero mobile data required).
