# MPEPE STUDIO Feature Map

1. **All-in-One Inbox**: Centralized message consumption (`lib/social_hub/unified_inbox_screen.dart`).
2. **Command Palette**: Universal navigation and action execution bound to `Cmd+K` (`lib/shared/command_palette/`).
3. **Settings Center**: Granular control over privacy, devices, AI, and accounts (`lib/settings/settings_center_screen.dart`).
4. **Analytics Dashboard**: Real-time aggregation of workspace metrics (`lib/backend/analytics/`).
5. **Workflow Automation**: GUI-driven background automations with loop prevention (`lib/backend/automations/`).
6. **Global Search**: ACL-enforced semantic and exact search (`lib/backend/search/`).
