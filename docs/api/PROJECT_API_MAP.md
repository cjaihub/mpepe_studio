# MPEPE STUDIO API Map

For the exhaustive list of external REST/Cloud Function routes, refer to `docs/API_INVENTORY.md`.

## Internal Service Boundaries
- `SystemStatusService`: Real-time health monitoring.
- `AiSecurityGateway`: Tool execution boundary for AI models.
- `WorkflowEngine`: Event-driven automation processing.
- `GlobalSearchService`: Index querying and ACL application.
- `AnalyticsService`: Live metric aggregation.
